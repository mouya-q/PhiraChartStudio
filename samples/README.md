# Example Phira package

`ExampleChart.pez` is a self-contained, synthetic 120 BPM test chart. The WAV is generated locally from a click-and-pad signal; it contains no commercial recording. The package has the four root entries expected by this generator: `info.yml`, `chart.json`, `background.png` and `song.wav`.

The ZIP was checked for exact root entry names, duplicate-free contents, CRC integrity, a valid JSON RPE root, RPE version 160, BPM metadata and the Phira `info.yml` pointers. This does **not** replace a real import / playback test in the current Phira app.
